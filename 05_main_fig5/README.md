# Main Figure 5: validated limb versus non-limb Gli3-region enhancer comparison

This module supports Main Figure 5 of the September 2026 manuscript revision.

Main Figure 5 compares 13 curated functionally supported Gli3 limb enhancers
with 41 validated non-limb enhancers from the broader Gli3 region. Panels A-D
show representative signal distributions, and panel E summarizes single-layer
AUC values.

The comparison evaluates whether higher bulk chromatin or transcription-factor
signal alone distinguishes validated limb enhancers from validated non-limb
enhancers. The substantial overlap between classes supports cautious
interpretation of individual genomic signal layers rather than functional
classification from any single dataset.
